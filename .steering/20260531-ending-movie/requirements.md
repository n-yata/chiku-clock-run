# 要求内容

## 概要

全ステージ（STAGE 3）クリア時に、現状の「`ALL CLEAR!` テキスト表示のみ」を、専用のエンディングムービー（カットシーン）に置き換える。集めた歯車で止まっていた工房の大時計を修理し、時計が動き出し、曇り空が晴れてハッピーエンドに至る一連の演出を見せる。

## 背景

- 現状、全クリア時の演出は `GameScene.showAllClear()` による「`ALL CLEAR!` ＋ 歯車カウント ＋ サフィックステキスト」表示と、数秒後のタイトル自動復帰のみ。ゲームの締めくくりとしての達成感・物語性が乏しい。
- 本作の世界観は「時計工房を舞台にした 2D プラットフォーマー」であり、歯車を集める動機づけ（時計を直す）に対する**ペイオフ（報酬体験）が存在しない**。
- プレイヤーが集めてきた歯車が「時計の修理」という形で報われ、世界が好転する様子を見せることで、ゲーム全体の物語を完結させる。

## 実装対象の機能

### 1. エンディングシーン（EndingScene）

- 全ステージクリア時に GameScene から専用の Phaser Scene（`EndingScene`）へ遷移する。
- GameScene の地形・敵・カメラから切り離された独立シーンで演出を制御する。
- 演出はすべてプログラム描画（Canvas API によるテクスチャ生成 ＋ Phaser Tween）で構成し、新規画像アセットは追加しない（既存のトーンに統一）。

### 2. エンディング演出（絵巻シーケンス）

以下のシーケンスを順送りで再生する:

1. **暗転からの導入** — 暗い工房に止まった大時計。針は動いていない。曇り空（暗い背景）。
2. **歯車の組み込み** — 集めた歯車が時計内部にはまり込んでいく（複数の歯車が回転しながら所定位置へ）。
3. **時計の始動** — 歯車が噛み合い、時計の針が動き出す（チクタク。秒針が回る）。
4. **空が晴れる** — 背景が暗い曇り空から明るい青空へグラデーションで遷移。光が差す。
5. **ハッピーエンド** — 主人公チクと修理された時計を中心に、祝祭的な演出（パーティクル等）＋ エンディングメッセージ表示。

### 3. スキップとタイトル復帰

- 演出中、タップ／キー入力でスキップして最終カットへ即時遷移できる。
- 演出完了後、一定時間で自動的に TitleScene へ戻る（現状の挙動を踏襲）。

## 受け入れ条件

### エンディングシーン（EndingScene）

- [ ] STAGE 3 のゴール到達時、EndingScene へ遷移する
- [ ] EndingScene は GameScene の物理ワールド・敵・地形に依存せず単独で動作する
- [ ] 演出中は BGM が停止または専用 BGM に切り替わる（既存 AudioManager を利用、無音でも可）
- [ ] 新規画像ファイル（PNG 等）を追加していない（描画はコード生成）

### エンディング演出（絵巻シーケンス）

- [ ] 「止まった時計 → 歯車が組み込まれる → 針が動き出す → 空が晴れる → ハッピーエンド」の順で再生される
- [ ] 背景が暗い空から明るい空へ視覚的に変化する
- [ ] 時計の針が静止状態から回転（動作）状態へ変化する
- [ ] 集めた歯車数がエンディング内で参照・表示される（達成感の提示）

### スキップとタイトル復帰

- [ ] 演出中にタップ／キー入力で最終カットへスキップできる
- [ ] 演出完了後、自動的に TitleScene へ遷移する
- [ ] スキップ後も最終的に TitleScene へ遷移する（多重遷移しない）

## 成功指標

- 全クリア時に「歯車を集めた意味」が視覚的に伝わり、物語が完結したと感じられる。
- 既存のゲームループ（ステージ進行・リスタート）を壊さない。
- 追加アセット 0・トーン統一で、ビルドサイズや読み込みに大きな影響を与えない。

## スコープ外

以下はこのフェーズでは実装しません:

- 新規 BGM トラックの本格的な作曲（既存 AudioManager の範囲で対応、専用ジングルは任意）
- セーブデータ・クリア実績の永続化（クリア回数記録等）
- ボイス・動画ファイル（mp4 等）の埋め込み
- 多言語対応（エンディングメッセージのローカライズ）
- ステージ追加・難易度調整

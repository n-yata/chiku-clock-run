## D-1: `'P'` / `'G'` タイルを「スプライトの足元が乗るセル」と再定義

**日付:** 2026-05-04
**関連:** v0.1 デプロイ後、Pages 上での実機確認時に発覚

### Why

- 当初実装では `spawnY = spawnRow * TILE_SIZE + TILE_SIZE / 2`（タイル中心）にプレイヤーを配置
- `'P'` が行15（床直上の空中セル）の例: プレイヤー中心 Y=496、プレイヤー高 48 → 足元 Y=520
- 床（行16）の上端 Y=512 に対して **足元が 8px めり込んだ状態でスタート**
- Phaser Arcade Physics はめり込みを解消できず、トンネル現象でプレイヤーが地面を貫通して落ち続ける
- 同様に `'G'` も中心配置だと床から半分埋もれる

### Decision

`GameScene.buildStage()` の Y 計算を、足元基準に変更:

- `spawnY = (spawnRow + 1) * TILE_SIZE - PLAYER_SPRITE_H / 2`
- `goalY  = (goalRow  + 1) * TILE_SIZE - GOAL_SPRITE_H  / 2`

これにより `'P'` / `'G'` タイルは **「スプライトの足元が乗るセル」** という意味になり、スプライト下端 = `(row + 1) * TILE_SIZE` で床にぴったり立つ（または床から `(rows-1 - row) * TILE_SIZE` 浮く）。

ステージ定義 `stage01.ts` の文字配置はそのまま。

### Consequence

- プレイヤー貫通バグ解消、地面の上に正しく立つ
- 既存ステージの `'P'`（行15）・`'G'`（行14）の意図そのままで動作（スポーンは床直上、ゴールは床から 1 タイル分上に浮く）
- 将来ステージ追加時のタイル配置ルールが「スプライトの足元 = タイル位置」で統一される
- リスク: スプライト高がタイル高より大きい場合（`PLAYER_SPRITE_H=48` > `TILE_SIZE=32`）、スプライト上端は配置タイルより上の空中セルにはみ出す。レベル設計時に「足元タイルから上方向に余白を取る」必要あり（v0.2 で他敵キャラ追加時の設計指針）

## D-2: タッチ操作（左 / 右 / ジャンプ）を v0.1 のスコープに追加

**日付:** 2026-05-04
**関連:** v0.1 デプロイ後、シャビが実機（Dev Container 環境）で動作確認時に発覚

### Why

- `requirements.md §3.2` で「モバイルタッチ操作」は v0.2 以降に明示的に除外していた
- しかしシャビの開発環境が Dev Container 内で完結しており、PC ブラウザでのキーボード操作確認手段が事実上存在しない
- スマホで Pages を開いて確認しようとしても、キーボード前提のため操作不能 → **動作確認自体が不可能**
- 「v0.1 を動作確認可能にする」要件と「タッチ操作除外」要件が両立しない

### Decision

最小実装のタッチ操作を v0.1 ホットフィックスに追加:

- 画面下部に半透明の 3 ボタン（左 `←` / 右 `→` / ジャンプ `↑`）を Phaser 固定 UI として配置（`setScrollFactor(0)` + `setInteractive()`）
- `pointerdown` / `pointerup` / `pointerout` / `pointerupoutside` で内部フラグ（`touchLeft` / `touchRight` / `touchJump`）を管理
- `update()` ではキーボード入力と OR 合成（`leftDown = cursors.left?.isDown || touchLeft`）
- クリアテキストを `setInteractive()` 化し、タップでも `scene.restart()` を発火（R キー相当）

### Consequence

- スマホ（タッチ）/ PC（キーボード）どちらでも動作確認・プレイ可能
- `requirements.md §3.2` の除外項目「モバイルタッチ操作」は **本決定で取り下げ**。代わりに「最小限のタッチ操作」が v0.1 スコープに含まれる
- v0.2 でタッチ UX を本格化する際は、ボタン配置・サイズ・押下フィードバックを再設計予定（現状は「動作確認のための最小ボタン」レベル）
- 追加依存ゼロ、CSP 変更なし、外部通信なし。セキュリティ影響軽微

# requirements.md — 新敵タイプ追加（時計トンボ / チクタク爆弾）

## 1. 背景・目的

現状、敵キャラは「巻きネジ機（地上を歩いて端で反転する単眼オートマトン）」の 1 種類のみ。
ステージが進んでも敵の挙動が単調で、難易度の質的な変化が乏しい。
そこで **動きの軸が異なる新敵 2 種**を追加し、ステージごとの敵バリエーションを増やして
攻略の幅と緊張感を高める。

## 2. スコープ

### 2.1 確定ラインナップ

| ステージ | 役割 | 敵構成（種類数） |
|---|---|---|
| 1 (stage01) | intro | 巻きネジ機のみ（**据え置き・変更なし**） |
| 2 (stage02) | intermediate | 巻きネジ機 ＋ **時計トンボ**（2 種） |
| 3 (stage03) | final | 巻きネジ機 ＋ 時計トンボ ＋ **チクタク爆弾**（3 種） |

### 2.2 新敵 A：時計トンボ（飛行）

- 真鍮の機械トンボ。空中を**水平巡回しつつ上下にサインカーブで揺れる**。
- 重力無効。地形を無視するため「地上に居れば安全」が通じない＝**空の脅威**。
- 上から踏めば撃破。横・下から触れると被弾。

### 2.3 新敵 B：チクタク爆弾（追尾自爆）

- 時計の文字盤を持つ丸い爆弾ロボ。普段は鎮座。
- プレイヤーが**検知範囲に入ると追尾**し、**至近距離で導火（点滅テレグラフ）→ 自爆**。
- 自爆時、**爆発範囲内のプレイヤーにダメージ**（範囲攻撃）。踏めば爆発前に解除（撃破）可能。
- 地上設置（真下が地面 `#` 必須）。崖際では落下せず停止。

## 3. 機能要件

- FR-1: 新タイルチャー `'F'`（時計トンボ）/ `'B'`（チクタク爆弾）でステージ配置できる。
- FR-2: `'F'` は空中セルに配置（地面下不要）。`'B'` は真下が `#` 必須。
- FR-3: 3 種の敵は 1 つの enemies グループに混在し、種別（`type`）で AI が分岐する。
- FR-4: 既存「踏みつけ撃破 → バウンド + ヒットストップ + 消滅バースト」は 3 種共通で動作する。
- FR-5: 時計トンボは重力無効・水平巡回（壁/巡回範囲端で反転）＋上下サイン揺れ。
- FR-6: チクタク爆弾は idle → 追尾 → 導火 → 自爆 の状態遷移を持ち、自爆は範囲ダメージ＋専用演出。
- FR-7: 難易度メトリクス（`measureStageDifficulty`）の敵カウントに `'E'`+`'F'`+`'B'` を合算し、
  ステージ進行で難易度スコアが単調増加する制約を維持する。
- FR-8: 既存の到達可能性検証（criticalPath クリアランス）を侵さない配置とする。

## 4. 非機能要件

- NFR-1: 60fps を維持（常時稼働 emitter を増やさない。爆発は単発バースト）。
- NFR-2: 直値直書き禁止。寸法・速度・色・しきい値は `gameConfig.ts` へ集約。
- NFR-3: スプライトは既存のプロシージャル描画方式（高解像度 → ダウンスケール）に揃える。
- NFR-4: 既存の stage01 と E2E ビジュアル検証を壊さない。

## 5. 受け入れ条件

- AC-1: stage02 に時計トンボ、stage03 に時計トンボ＋チクタク爆弾が出現する。
- AC-2: 時計トンボを踏んで撃破できる／空中で被弾する。
- AC-3: チクタク爆弾が追尾し、至近で自爆して範囲ダメージを与える／踏むと解除できる。
- AC-4: `npm run typecheck` と `npm run build` がエラーなく通る。
- AC-5: 難易度進行検証（`validateDifficultyProgression`）がパスする。

## 6. 非スコープ

- stage01 の内容変更。
- 新ステージ追加・既存地形（床・ピット・足場）の再構築。
- ボス・体力ゲージ等の大型システム。

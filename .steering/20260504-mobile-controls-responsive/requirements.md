# 要求書: スマホ操作改善 & レスポンシブ対応

| 項目 | 内容 |
|------|------|
| 作成日 | 2026-05-04 |
| 担当 | モドリッチ |
| 関連スプリント | `.steering/20260504-v0.2-enemies-coins/`（前スプリント）|

---

## 1. 背景

### 1.1 現状

- タッチ操作は「画面左半分：短押しジャンプ / 長押し左移動」「画面右半分：短押しジャンプ / 長押し右移動」という複合操作（`TOUCH_HOLD_MS = 180ms` の長押し判定）
- 操作の直感性に欠けており、ジャンプと移動が同じ手 / 同じ領域で混在しているためミス操作が多い
- スマホ横向き（landscape）では `Phaser.Scale.FIT` により一応表示されるが、viewport の `user-scalable` 未設定でピンチズームが誤動作する
- 縦向き（portrait）ではゲーム領域が縦方向に極端に縮小され、タッチ操作エリアが狭くなる
- インストラクションテキスト（`setupTouchControls` 内）が現状操作と合わない状態（変更後に要更新）

### 1.2 やりたいこと

- タッチ操作を「左半分＝スライドで左右移動」「右半分＝ジャンプ専用」に完全分離して操作を直感的にする
- 縦向き / 横向きをCSSで適切にレスポンシブ対応し、横向きを推奨する設計にする

---

## 2. ゴール

### 2.1 主目的

- スマホ操作のミス操作を減らし、初見プレイヤーが説明なしで遊べるようにする
- 横向きスマホでゲームエリアが最大限活用される表示を実現する

### 2.2 副次目的

- `TOUCH_HOLD_MS` を使った長押し判定ロジックの削除によりコード簡素化
- viewport / CSS 整備により将来の UI 追加（バーチャルボタン等）の土台を作る

---

## 3. スコープ

### 3.1 含むもの

- タッチ操作ロジック刷新（`src/scenes/GameScene.ts`）
  - 左半分：ポインタダウン位置を基準にX軸スライドで左右移動、離したら停止
  - 右半分：タッチダウン瞬間にジャンプ発火（離さなくてよい）
- 定数整理（`src/config/gameConfig.ts`）
  - `TOUCH_HOLD_MS` を削除、スライド判定しきい値 `TOUCH_SLIDE_THRESHOLD_PX` を追加
- レスポンシブ対応（`index.html`）
  - `viewport` に `user-scalable=no` 追加
  - CSS `@media (orientation: portrait)` でゲームキャンバスに回転促進オーバーレイを表示
  - CSS `@media (orientation: landscape)` でゲームエリアを画面全域に最大化
- インストラクションテキスト更新（操作説明の文言変更）
- `docs/architecture.md` の入力仕様欄更新（P6フェーズ）

### 3.2 含まないもの

- 仮想ボタン / 仮想ジョイスティックの描画 UI（今回はゾーン分割のみ）
- PC キーボード操作への変更（現状維持）
- 複数タッチ（マルチタッチ）対応（両手同時操作 etc.）
- BGM / SE、ステージ追加などゲームコンテンツの変更

## 4. 機能要件

### 4.1 タッチ操作: 左半分（移動ゾーン）

1. 画面左半分（`pointer.x < scale.width / 2`）にタッチダウンした時点の X 座標を基準位置として記録する
2. タッチ中に `pointermove` が発火するたびに、現在X − 基準X を計算する
3. 差分が `+TOUCH_SLIDE_THRESHOLD_PX` を超えたら右移動、`-TOUCH_SLIDE_THRESHOLD_PX` を下回ったら左移動、しきい値内なら停止
4. タッチアップで移動停止・基準位置をリセットする

### 4.2 タッチ操作: 右半分（ジャンプゾーン）

1. 画面右半分（`pointer.x >= scale.width / 2`）にタッチダウンした瞬間（`pointerdown`）にジャンプを発火する
2. 地面に接触していない場合はジャンプしない（既存ロジック維持）
3. タッチを押し続けても追加ジャンプはしない（タップした瞬間に1回だけ）
4. タッチアップでのジャンプ発火（現状）は廃止する

### 4.3 レスポンシブ / 縦横向き対応

1. `index.html` の `<meta name="viewport">` に `user-scalable=no, minimum-scale=1, maximum-scale=1` を追加してピンチズームを禁止する
2. 縦向き（portrait）時：「横向きにして遊んでね」などのオーバーレイを CSS のみで表示し、Phaser キャンバスを覆う
3. 横向き（landscape）時：オーバーレイを非表示にし、ゲームキャンバスが画面全域を占める
4. Phaser の `scale.mode` は `FIT + CENTER_BOTH` を維持し、CSS と協調させる

### 4.4 既存機能の互換要件

- PC キーボード（←/→/Space/↑/R）の操作は一切変更しない
- ゴール判定 / ミス判定 / 敵 AI / コイン取得の既存ロジックは変更しない
- `window.location.reload()` によるリスタート仕様は変更しない

## 5. 非機能要件

### 5.1 パフォーマンス

- `pointermove` イベントが毎フレーム多数発火するため、判定ロジックは O(1) の単純比較に留める
- 入力レイテンシ < 100 ms（既存要件を維持）

### 5.2 信頼性

- タッチ途中でゲームクリア / ミスが発生した場合、移動状態が残らないよう `isMissed` / `isCleared` チェックを維持する
- `pointerupoutside` も引き続き `pointerup` と同一ハンドラで処理する

### 5.3 互換性・依存

- フロント: Phaser 3.80（追加ライブラリなし）、対応ブラウザ（最新 Chrome / Safari / Firefox / Edge）
- ハードコーディング禁止: しきい値・定数は `src/config/gameConfig.ts` に集約。マジックナンバー禁止

### 5.4 セキュリティ

- タッチ座標はゲームロジック内部でのみ使用し、外部送信しない
- CSS オーバーレイのコンテンツはリテラル文字列のみ（XSS リスクなし）
- CSP（`index.html` の `<meta http-equiv="Content-Security-Policy">`）は変更しない

---

## 6. 制約・前提条件

- Phaser 3 の入力システム（`this.input.on('pointermove', ...)`）を使用。ブラウザネイティブの `addEventListener` は使わない
- `TOUCH_HOLD_MS` ベースの長押し判定ロジックは完全削除（後退しない）
- コミット前にクルトワ（security-engineer）レビュー必須
- dev サーバーは起動しない。確認は GitHub Pages デプロイ後にシャビが実施

## 7. 受け入れ条件

- [ ] 画面左半分でタッチしたまま右にスライドすると右移動、左にスライドすると左移動する
- [ ] 画面右半分タップでジャンプが発火する（地面接触中のみ）
- [ ] タッチを離すと移動が止まる
- [ ] PC キーボード操作（←/→/Space/↑/R）が従来通り動作する
- [ ] 縦向き表示時に「横向きにしてください」系のオーバーレイが表示される
- [ ] 横向き表示時にオーバーレイが消え、ゲームが全画面で動作する
- [ ] ピンチズームが無効化されている
- [ ] クルトワ（security-engineer）レビューで Critical/High なし

# 要求内容

## 概要

ステージ3クリア後に、専用の `BossScene` で「最後のボス」戦を追加する。ボスは時計工房の大時計を止めている元凶＝**振り子の大時計「グランドファーザー」**。撃破するとエンディング（大時計の修理→朝が戻る）へ繋がる。

## 背景

- 現状は stage03 のゴールに触れると即エンディングへ遷移し、物語のクライマックスとなる「対決」が存在しない。
- エンディングは「壊れた大時計を直して朝を取り戻す」演出。ボスを**その大時計を止めている存在**にすることで、ボス撃破→修理→夜明け、という一連の物語が成立する。
- プレイヤーの攻撃手段は「踏みつけ」のみ。新機構を増やさず、既存の踏みつけ撃破でボスを倒せる設計にする。

## 実装対象の機能

### 1. BossScene（専用ボス戦シーン）

- stage03 クリア後に独立シーンとして起動する。横スクロールは最小限の固定アリーナ。
- 既存の `PlayerController` / `CameraController` / `ParticleManager` / `HudManager` / `AudioManager` を再利用してプレイ感を統一する。
- ボス撃破で `EndingScene` へ、通算歯車数を引き継いで遷移する。
- 被弾・ライフ・ゲームオーバー・R リスタートは GameScene と同じ挙動。

### 2. ボス「グランドファーザー」（3フェーズ制）

- HP=3。`attack`（攻撃）→ `vulnerable`（弱点露出）を繰り返す状態機械。
- **攻撃**: 振り子が床を薙ぐスイープ + 上から歯車が降る（gear rain）。フェーズが進むほど振り子が速くなる。
- **弱点露出**: 一定間隔で弱点コア（光る歯車）が踏める高さまで降りてくる。プレイヤーはその窓で踏みつけて 1 ダメージ。
- 3 回踏むと撃破。崩壊演出 → エンディングへ。

### 3. ボス HP 表示

- 画面上部中央にボス HP バー（残り 3 段階）を表示する。ダメージで減る。

## 受け入れ条件

### BossScene
- [ ] stage03 のゴール到達後、`EndingScene` ではなく `BossScene` が起動する
- [ ] ボス撃破後に `EndingScene` が起動し、通算歯車数（collected/total）が正しく引き継がれる
- [ ] R キーでボス戦を最初からやり直せる
- [ ] ライフが 0 になるとゲームオーバー → タイトルへ戻る

### ボス「グランドファーザー」
- [ ] 振り子に接触するとライフが減る（残ライフ時はノックバック+無敵、0 で致命）
- [ ] 落下する歯車に接触するとライフが減る
- [ ] 弱点コアを上から踏むと boss HP が 1 減り、プレイヤーは跳ねる
- [ ] 弱点コアに横/下から接触すると被弾する（踏みつけ以外は無効）
- [ ] 弱点コアが露出していない間は踏んでもダメージが入らない（露出窓のみ有効）
- [ ] HP が 0 になると撃破演出が再生され、エンディングへ遷移する
- [ ] フェーズが進むほど振り子の速度が上がる（難度上昇）

### ボス HP 表示
- [ ] 画面上部にボス HP バーが表示され、被ダメージで残量が減る

## 成功指標

- 既存の操作（左右移動・ジャンプ・踏みつけ）だけでクリアできる（新操作を覚える必要がない）。
- `npm run typecheck` / `npm run lint` / `npm run build` が通る。
- 60fps を維持する（常時稼働パーティクル emitter を持たない既存方針を踏襲）。

## スコープ外

以下はこのフェーズでは実装しません:

- ボス専用の新規 BGM・効果音の追加（既存 SE を流用する）
- ボス用の新規画像アセット（PNG）追加（手続き的 Canvas/Graphics 描画と既存テクスチャ流用で対応）
- 複数ボス・ボスラッシュ
- ボス戦のスコア/ランキング機能

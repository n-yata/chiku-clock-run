# 決定事項ログ

## D-001: ボス可動物のテクスチャは「実寸ぴったりの手続き的生成」にする

- **日付**: 2026-06-02
- **背景**: design.md では振り子の錘・弱点コア・落下歯車を既存 `TEX_KEY.gearBit`（PNG）流用で表現する計画だった。
- **問題**: `gear-bit.png` のネイティブ寸法が不定で、`setDisplaySize` でスケールをかけると Arcade Body の `setSize`/`setCircle`（テクスチャ実寸基準）の当たり判定計算がスケール依存になり脆くなる。既存の敵スプライトは「フレーム実寸＝表示寸」（scale=1）で当たり判定を絞っており、この前提を踏襲したい。
- **決定**: ボス可動物用に、目標表示サイズと等しいサイズの手続き的 Canvas テクスチャ（`bossBob` / `bossGear` / `bossCore`）を `spriteSheets.ts` で生成し、`BootScene` で初期化する。これにより scale=1 が保たれ、`setCircle` の半径がそのままワールド px になる。
- **影響**: 新規 PNG アセットは追加しない（手続き的描画＝既存方針と整合）。requirements の「新規画像アセットを増やさない」は維持。`TEX_KEY` に 3 キー追加。

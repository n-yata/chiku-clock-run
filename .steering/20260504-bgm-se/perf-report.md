## 設計上の特記事項

- **バンドルサイズの制約対応**: 残余裕 10 kB の制約を踏まえ、外部音声ファイル（MP3/OGG）を一切使わず Web Audio API によるプログラム合成を採用。結果 +4 kB で収まった
- **iOS Safari unlock**: `AudioContext` を遅延生成し、最初のユーザー入力（`keydown` / `pointerdown`）のコールスタック内で生成・resume する設計。`unlock()` は冪等なので多重呼び出しは安全
- **60 fps 維持**: `GameScene.update()` ループから AudioManager を完全排除。SE はイベント駆動、BGM は `setInterval` + Web Audio API クロック駆動
- **フォールバック設計**: `AudioContext` 生成失敗時は全 API を no-op 化。音なしでゲームが継続する

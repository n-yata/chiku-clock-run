# 要求書: ファイアフラワー / スター追加パワーアップ

| 項目 | 内容 |
|------|------|
| 作成日 | 2026-05-05 |
| 担当 | モドリッチ |
| 関連スプリント | `.steering/20260505-life-powerup/`（ライフ/キノコ実装・前提） |

---

## 1. 背景

### 1.1 現状

- v0.9（`20260505-life-powerup`）完了後、プレイヤー状態は「小 / 大」の 2 値で管理される予定
- キノコ（mushroom）のみが実装済みパワーアップで、攻撃手段・特殊無敵状態は存在しない
- 敵への対処は「踏みつけ」のみ。遠距離攻撃がないため、接近戦でライフを失いやすい
- マリオ風アクションの代名詞である「ファイアボール投射」「スター無敵」が未実装であり、ゲームの深みが不足している

### 1.2 やりたいこと

**ファイアフラワー**と**スター（スターマン）**を新パワーアップとして追加し、  
攻撃の選択肢・緊急回避手段を増やして「戦略的プレイ」の幅を広げる。

スコープ外（後続に送るもの）: ファイア以外の追加状態（例: アイスフラワー）、  
ファイアボールの演出強化（爆発エフェクト）、BGM 切り替え（スター取得時の BGM 変化）。

---

## 2. ゴール

### 2.1 主目的

- ファイアボールで遠距離から敵を倒せるようになり、「攻略の選択肢」が増える
- スターで一定時間無敵になることで、「追い詰められた時の逆転手段」が生まれる
- プレイヤー状態が 3 段階（小 / 大 / ファイア）に拡張され、ゲームとしての深みが増す

### 2.2 副次目的

- プレイヤー状態マシンを 3 値に拡張することで、将来の状態追加（アイスフラワー等）の土台ができる
- ファイアボール（物理オブジェクト）の実装により、投射物システムの再利用基盤が生まれる
- スター無敵タイマー管理の実装で、時限バフ機構のパターンが確立される

---

## 3. スコープ

### 3.1 含むもの

- **ファイアフラワーアイテム**: ステージデータに新タイル `F` を追加。接触でファイア状態へ
- **プレイヤー状態の 3 値化**: `small → big → fire` の状態機械拡張（`PlayerState` 型）
- **ファイアボール投射**: ファイア状態中に Z キー / タップで前方へ投射（最大同時 2 発）
- **ファイアボール ↔ 敵衝突**: ファイアボールが敵に当たると敵撃破 + ファイアボール消滅
- **スター（スターマン）アイテム**: ステージデータに新タイル `S` を追加。接触で無敵状態へ
- **スター無敵**: 取得後 `STAR_INVINCIBLE_MS`（ms）間、敵接触でライフ減算なし + 敵撃破
- **HUD 更新**: ファイア状態・スター無敵中の視覚フィードバック（スプライト色変化 / 点滅）
- **既存機能の温存**: ライフシステム・キノコ・3 ステージ進行・BGM/SE・タッチ操作を維持

### 3.2 含まないもの

- BGM 切り替え（スター取得時のBGMへの変化）
- ファイアボール爆発エフェクト（パーティクル等）
- アイスフラワー・ペンギンスーツ等の追加パワーアップ（後続スプリントで検討）
- ファイアボール SE 以外の SE 追加（SE は coin / stomp / miss 等の既存を最大限流用）
- コンティニュー時のパワーアップ状態引き継ぎ（ゲームオーバー後はリセット）

---

## 4. 機能要件

### 4.1 プレイヤー状態拡張

1. `PlayerState = 'small' | 'big' | 'fire'` 型を定義（`src/types/` 等に切り出し可）
2. ファイアフラワー取得時の状態遷移:
   - `small` → `fire`（小でも直接ファイア状態になる）
   - `big`  → `fire`
   - `fire` → `fire`（重複取得は無視。SE のみ再生）
3. 敵接触時のダメージ遷移（スター無敵中を除く）:
   - `fire` → `big`（ライフ減算なし、無敵フレーム付与）
   - `big`  → `small`（ライフ減算なし、無敵フレーム付与）
   - `small` → ライフ −1（無敵フレーム + 既存ミス演出）
4. 落下ミスは状態に関わらず常にライフ −1（既存挙動を維持）
5. ステージ遷移時もパワーアップ状態を引き継ぐ（`data` に `playerState` を追加）

### 4.2 ファイアフラワーアイテム

1. ステージデータにタイル `F` を追加可能にする（`buildStage()` バリデーションに `F` を追加）
2. ファイアフラワーは `StaticGroup` で配置。プレイヤーとの overlap で取得・消滅
3. 取得時: プレイヤー状態を `fire` に変更 + SE 再生（`coin` SE を流用 or 新規 `powerup` SE）
4. ファイア状態のスプライト: `setTint` で色変化（例: 赤系 → 橙系）で視覚的に区別

### 4.3 ファイアボール投射

1. ファイア状態中に Z キー（キーボード）または画面タップ長押し / 専用ボタン（タッチ）で投射
2. ファイアボールは `Group` で管理。同時存在数は最大 `FIREBALL_MAX_COUNT = 2` 個
3. ファイアボールの物理挙動:
   - 初速: 水平 `FIREBALL_SPEED_X`、初期垂直速度 `FIREBALL_SPEED_Y`（斜め下向き）
   - 地面に当たるたびに反発（bounceY）。`FIREBALL_BOUNCE_COUNT` 回反発後に消滅
   - 画面端 / ステージ右端に達したら消滅
4. ファイアボール ↔ 敵の overlap: 敵撃破（stomp SE 流用）+ ファイアボール消滅
5. ファイアボール ↔ 地形: 反発（地形 tilemap との衝突で自然に跳ねる）
6. ファイアボールのスプライト: `generateTexture` でオレンジ色の小円（`TEX_KEY.fireball`）

### 4.4 スター（スターマン）アイテム

1. ステージデータにタイル `S` を追加可能にする（`buildStage()` バリデーションに `S` を追加）
2. スターは `StaticGroup` で配置。プレイヤーとの overlap で取得・消滅
3. 取得時: スター無敵フラグ ON + `STAR_INVINCIBLE_MS`（ms）のタイマー開始 + SE 再生
4. スター無敵中の挙動:
   - 敵に接触 → 敵撃破（ライフ減算なし）
   - プレイヤーが点滅（`setAlpha` を交互切替）で視覚フィードバック
5. タイマー終了後: スター無敵フラグ OFF、点滅終了、状態は取得前のまま維持
6. スター重複取得: タイマーをリセット（無敵時間を延長）

### 4.5 既存機能の互換要件

- キノコ取得（`small → big`）は変更なし
- ライフ HUD・コイン HUD・ステージ HUD は変更なし
- 既存の踏みつけ（stomp）ロジックはファイア状態でも動作すること
- BGM / SE・タッチ操作・3 ステージ進行・タイトル画面は変更なし

## 5. 非機能要件

### 5.1 パフォーマンス

- ファイアボール（最大 2 発）追加後も 60fps 維持
- ファイアボール Group は `maxSize` を `FIREBALL_MAX_COUNT` に制限し、オブジェクトプールを活用

### 5.2 信頼性

- ファイアボール数が `FIREBALL_MAX_COUNT` を超えて生成されない（上限ガード必須）
- スター無敵タイマーはシーン遷移（ステージ移動）時にクリアする
- ファイア状態でゲームオーバーになった場合、次プレイは `small` でリスタート

### 5.3 互換性・依存

- フロント: Phaser 3.80 の既存 API のみ使用（追加 npm パッケージ禁止）
- ハードコーディング禁止: ファイアボール速度・最大発射数・スター無敵時間等の定数は `src/config/gameConfig.ts` に集約
- `PlayerState` 型は `src/config/gameConfig.ts` or `src/types/player.ts` に定義（design.md でバルベルデが確定）

### 5.4 セキュリティ

- バックエンドなし。ユーザー入力はキーイベント・タッチ座標のみ
- Phaser テキストに渡す文字列はリテラル定数か数値型に固定（XSS の余地なし）
- クルトワ（security-engineer）レビュー必須（コミット前）

---

## 6. 制約・前提条件

- **前提**: `20260505-life-powerup` スプリントが完了済みであること（プレイヤー状態 `small/big`・ライフシステム・キノコ実装）
- Phaser 3.80 の `physics.add.group`・`setTint`・`setAlpha`・`time.addEvent` 等の既存 API で実装する
- ファイアフラワー・スター・ファイアボールのスプライトは `BootScene` の `generateTexture` でプログラム生成（外部アセット導入は本スプリント外）
- タッチ操作でのファイアボール投射 UI は design.md でバルベルデが方針を確定する（専用ボタン追加 or 既存操作拡張）
- コミット前は必ずクルトワ（security-engineer）レビューを実施すること

---

## 7. 受け入れ条件

- [ ] ファイアフラワーを取るとプレイヤーがファイア状態になり、スプライト色が変わる
- [ ] Z キー（またはタッチ操作）でファイアボールを前方に投射できる
- [ ] ファイアボールが最大 2 発同時に存在し、3 発目は発射されない
- [ ] ファイアボールが地面で跳ね、敵に当たると敵が撃破される
- [ ] ファイア状態で敵接触 → ビッグ状態に戻る（ライフ減算なし・無敵フレームあり）
- [ ] スターを取ると点滅しながら一定時間無敵になる
- [ ] スター無敵中に敵に触れると敵が撃破される（ライフ減算なし）
- [ ] スター無敵時間終了後、状態が取得前に戻る
- [ ] ステージをまたいでパワーアップ状態が引き継がれる
- [ ] ゲームオーバー後の再スタートは `small` 状態から始まる
- [ ] 既存の踏みつけ・ライフシステム・キノコ・3 ステージ進行・BGM/SE が壊れていない
- [ ] `npm run build` が TypeScript エラーなしで通る
- [ ] クルトワ（security-engineer）レビューで Critical/High なし

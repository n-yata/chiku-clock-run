## 1. 背景

### 1.1 現状

現在の主人公スプライトは赤い帽子と青い服の配色で、既存の有名な横スクロールアクション主人公を強く連想させる。
ゲーム性はジャンプ、移動、敵の踏みつけ、ステージクリアを中心に成立している。
ユーザー要望では、この操作感は維持しつつ、キャラクターにオリジナル性を持たせたい。

### 1.2 やりたいこと

主人公を小さな時計職人「チク」として再設計し、見た目とタイトルを時計職人テーマへ寄せる。
ジャンプして敵を倒す基本ゲーム性は変更しない。

---

## 2. ゴール

### 2.1 主目的

- 主人公の赤帽子・青オーバーオール風の印象をなくし、時計職人「チク」として識別できる見た目にする。
- ターゲット値: プレイヤーの主要配色を赤/青中心から深緑/真鍮/白/茶中心へ変更する。

### 2.2 副次目的

- タイトル表示を「チク」テーマへ変更する。
- 成長アイテムの見た目を赤いキノコ風から時計部品風へ寄せる。

---

## 3. スコープ

### 3.1 含むもの

- `src/config/gameConfig.ts` の表示文言・キャラクター配色定数の更新。
- `src/scenes/spriteSheets.ts` のプレイヤー生成ロジック更新。
- 既存 E2E テストの期待靴色の維持。
- `npm run build` と必要な E2E での確認。

### 3.2 含まないもの

- ジャンプ、踏みつけ、移動、敵 AI、ステージ構造の変更。
- 武器や新しい攻撃アクションの追加。
- 新しい外部アセットや外部通信の追加。

---

## 4. 機能要件

### 4.1 キャラクターデザイン

1. 主人公名は「チク」とする。
2. 見た目はゴーグル付き作業帽、深緑のベスト、白シャツ、真鍮パーツ、茶色ブーツを基本とする。
3. フレーム下端まで靴を描画し、既存の足元接地テストを維持する。

### 4.2 既存機能の互換要件

- プレイヤーのサイズ、物理 body、足元配置は変更しない。
- 既存のステージ定義とタイル記号は変更しない。
- Phaser の内部生成テクスチャ方式を維持する。

---

## 5. 非機能要件

### 5.1 パフォーマンス

- 既存と同じ Canvas 生成方式を使い、追加依存や外部画像読み込みを増やさない。

### 5.2 信頼性

- 既存の build と E2E が通ること。

### 5.3 互換性・依存

- フロント: Phaser 3 / Vite / TypeScript の既存構成を維持。
- バックエンド: なし。
- ハードコーディング禁止: 表示文言・色・寸法は `src/config/gameConfig.ts` に集約する。

### 5.4 セキュリティ

- 外部 URL、API、ユーザー入力、認証は追加しない。
- CSP 変更は行わない。

---

## 6. 制約・前提条件

- コミット前はクルトワレビュー必須。
- 既存の E2E が足元ピクセルを検証しているため、靴色と下端描画は維持する。

---

## 7. 受け入れ条件

- [ ] タイトルが「CHIKU CLOCK RUN」へ変更されている。
- [ ] プレイヤーが赤帽子・青オーバーオール風ではなく、時計職人チクとして描画される。
- [ ] ジャンプ、踏みつけ、ステージ開始の既存挙動が壊れていない。
- [ ] `npm run build` が成功する。
- [ ] `npm run test:e2e` が成功する。
- [ ] クルトワ（security-engineer）レビューで Critical/High なし。

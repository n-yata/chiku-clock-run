# 要求内容

## 概要

ラスボス「グランドファーザー」の戦闘を「振り子の錘を上から踏んでダメージを与える」方式に刷新し、
登場・撃破演出を強化する。あわせて通常3ステージ（stage01/02/03）に回復アイテム「予備ゼンマイ」を
1つずつ配置し、取得でライフを +1（上限3）回復できるようにする。

> 出発点: `.steering/20260603-boss-rework-and-heal-items/idea.md`

## 背景

- **ボス戦が単調**: 現状は「攻撃フェーズで振り子を避け、無敵フェーズで露出する弱点コアを踏む」方式。
  攻撃が2種・撃破演出も簡素で、最終決戦の盛り上がりに欠ける。踏みつけを能動的な仕様へ変えて手応えを上げたい。
- **回復手段が無い**: 被弾ライフ制（`INITIAL_LIVES=3`）だが道中に回復が一切なく、難所での再挑戦性が低い。

## 実装対象の機能

### 1. ボス戦リワーク（踏みつけ対象の変更）
- 弱点コア（`core`）の踏みつけを廃止する。
- 攻撃フェーズで振れている振り子の錘（`bob`）を**上から踏む**とボスにダメージ（HP-1）。
- 横/下から錘に触れると従来どおり被弾（`handleMiss('enemy')`）。
- 踏み成功直後はボスが短くよろける（`stagger`）。この間は錘の当たり判定を無効化し、再ヒット不可。
- よろけ終了後は攻撃へ戻り、振り子の角速度が1段上がる（既存のフェーズ加速を継続）。

### 2. ボス演出強化
- **登場**: チャイム的SE・カメラの軽い揺れ/フラッシュで番人の登場を印象づける。
- **撃破**: 爆発バーストの増量、大時計のフェード崩壊、振り子の落下、スローモーション風の溜め、
  カメラフラッシュを加えて決着を盛り上げる。
- 既存の質感（時計工房の夜景・真鍮色）を壊さない範囲で強化する。

### 3. 回復アイテム「予備ゼンマイ」
- 新タイル文字 `'H'` を定義し、stage01/02/03 に**ちょうど1つずつ**配置。
- プレイヤーが触れると**ライフ +1（上限3 = `INITIAL_LIVES` でキャップ）**、HUD に即反映。
- 取得時にパーティクル＋SE を再生し、スプライトは消費（`disableBody`）。
- ボス戦アリーナには配置しない。

## 受け入れ条件

### ボス戦リワーク
- [ ] 攻撃中の振り子の錘を上から踏むとボスHPが1減り、プレイヤーは跳ね返る（バウンド＋ヒットストップ）。
- [ ] 錘に横/下から触れると被弾し、残ライフがあれば無敵＋ノックバックで復帰、尽きると致命。
- [ ] 踏み成功直後の `stagger` 中は錘の当たり判定が無効で、多重ヒットしない。
- [ ] HP=0 で撃破され、`onHpChanged`/HPバーが正しく減り、最終的に EndingScene へ遷移する。
- [ ] 旧コア（`core` 露出/踏み）の挙動・overlap が残っていない。

### ボス演出強化
- [ ] 登場時に追加演出（SE/揺れ/フラッシュ）が再生される。
- [ ] 撃破時に強化演出（バースト増量・大時計フェード・振り子落下・スロー・フラッシュ）が再生される。
- [ ] 演出後に従来どおり EndingScene へ遷移し、フローが壊れていない。

### 回復アイテム
- [ ] stage01/02/03 それぞれに `'H'` がちょうど1つ存在し、各ステージ生成時に検証される。
- [ ] 取得でライフ +1、ただし上限3でキャップ（満タン時に取得しても3のまま、スプライトは消費）。
- [ ] HUD のライフ表示が取得直後に更新される。
- [ ] 取得時にパーティクル＋SE が再生され、スプライトが消える。
- [ ] `'H'` 追加で `stageValidation` のクリアランス/難易度検査が壊れない。

## 成功指標
- `npm run typecheck` と `npm run build` がエラーなく通る。
- 既存ステージバリデーション（`validateCriticalPathClearance` / `validateDifficultyProgression`）が緑のまま。
- ボス戦・回復アイテムが実機（`npm run dev`）で意図どおり機能する。

## スコープ外

以下はこのフェーズでは実装しません:

- ボスへの新攻撃パターン（弾幕・地震等）の追加。
- 最大ライフ上限の拡張、回復アイテムのボス戦配置。
- 新規SE/BGMアセットの追加（演出は既存 `playSe` キーを流用）。

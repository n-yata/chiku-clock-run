# 要求内容 — UIチープさ抜本改善（リッチ化）

## 背景・課題

シャビから「今のUIがあまりにもチープ。何度UI改善を指示してもほとんど変わっていない」との強い指摘。
実画面スクショ（`tmp-shots/` 01〜04）で現状を確認し、チープさの主因を特定した。

### スクショで判明したチープさの主因（優先度順）

1. **HUD（文字）の崩れ — 最大の主犯**
   - STAGE(y16) / 歯車片(y40) / ライフ(y64) / 操作説明(y88) の4行が **24px フォントで重なって潰れている**。
   - HUD をワールド座標に置き **逆ズーム補正**しているため、カメラズームで文字が拡大されボヤけ・グリフ見切れが発生。
   - 背景パネルなし・余白なし・アイコンなしで、レイアウトとして破綻している。
2. **背景のタイリング継ぎ目 + 暗さ・濁り**
   - `tileSprite` の繰り返し境界（縦の継ぎ目）が見えて安っぽい。
   - 全体が暗く濁っており「時計工房」の世界観が伝わらない。
3. **キャラ（チク）・敵の没個性 + 演出不足**
   - 既存シルエットを温存したまま内部を描き直してきたため、何度直しても印象が変わらない（シャビの明確な指摘）。
   - 表示サイズが小さく（プレイヤー40×56 / 敵44×44）、ディテールが活きない。
   - 動き・取得・撃破などの juice が弱い。

## 方針（厳守事項）

- **元キャラのシルエットを温存しない**。チク・敵はゼロから新規設計する。
- **「解像度を上げるだけ」はリッチではない**。形・配色・世界観・演出をセットで作る。
- **盲目的なコード編集をしない**。各フェーズ後に必ずスクショで実画面を確認する。

## 受け入れ条件

- [ ] HUD の4要素が重ならず、グリフが見切れない。カメラズームでボヤけない（UIカメラ or 非ズーム描画）。
- [ ] HUD に視認性を上げる背景パネル/アイコンが入り、情報が一目で読める。
- [ ] 背景のタイリング継ぎ目が目立たず、明度・コントラストが改善し世界観が出る。
- [ ] チク・敵が新シルエットで明確な個性を持ち、表示サイズ見直しでディテールが視認できる。
- [ ] 取得/撃破/着地/クリアなどの演出（juice）が体感で強化されている。
- [ ] `npm run typecheck` / `npm run build` / `npm run test:e2e` が緑。
- [ ] 各フェーズ完了時にスクショを撮り、改善が視認できることを確認した。

## スコープ外

- ステージ構成・難易度・物理パラメータの変更（見た目・演出に限定）。
- バックエンド追加（本プロジェクトは静的サイト）。

# 決定事項ログ — UIチープさ抜本改善（リッチ化）

実装中に発生した判断を時系列で記録する。

---

## 2026-05-30

### DEC-001: HUD は UIカメラを使わず「単一カメラ + setResolution/setScale」方式にする
- **背景**: design P1 は HUD 専用 UIカメラ（zoom=1）導入を想定。
- **問題**: `ParticleManager` がバースト毎に emitter を遅延生成するため、UIカメラの ignore リスト管理が複雑化し、後から生成される world オブジェクトが UIカメラにも描画される二重描画リスクがあった。
- **決定**: 単一カメラのまま、HUDテキストを `setResolution(zoom×dpr)` で鮮明化し `setScale(1/zoom)` でスクリーン実寸を一定化する。位置は既存の scrollFactor0 + ズーム逆変換を流用。
- **結果**: ズーム1.5でも文字が鮮明・等倍。行間（HUD_LINE_GAP）で重なり解消。半透明角丸パネル + 歯車アイコンを追加。E2E 9/9 緑。

### DEC-002: プレイヤー靴の接地を drawShoe/drawChikuFeet で回復
- **背景**: 未コミットだったプレイヤー高解像度新描画で、靴底の影色・暗いストロークが `PLAYER_SHOE_COLOR`(±12) に一致せず、E2E「足の接地 ≤4px」が 6px で失敗。
- **決定**: 足の bottom を frame 下端付近（~190/192）まで下げ、靴底の影を最下部から少し上に置いて最下部を純色に保持。ストローク幅 3→2。
- **理由**: 「足が地面に着く」はどのキャラデザインでも必須要件のため、P3 リデザインでも無駄にならない。

### DEC-003: 背景は「シームレスタイル + 非タイルのオーバーレイ」の多層構成にする
- **背景**: 旧背景はタイル端をまたぐ歯車と縦パイプ(x=130)が 320px 毎に縦縞（継ぎ目）を生み、かつ #0a081a〜#140c08 と暗く濁っていた。
- **決定**: (1) タイルは平坦ベース + `tileWrap` で歯車/グローを8近傍ラップ + 目地周期を両軸でタイル化 + 縦パイプ撤去でシームレス化。(2) 明暗グラデ・ビネット・暖色グローはタイルに焼かず、画面固定の非タイルオーバーレイ（`buildBackgroundOverlay`）として1枚重ねる。(3) 遠景にカメラ背景色 `BG_BASE_COLOR`。
- **理由**: グラデをタイルに焼くと両軸のタイル境界で必ず継ぎ目が出る。非タイルのオーバーレイに分離することで継ぎ目ゼロと世界観（コントラスト・奥行き）を両立。

### DEC-004: E2E 背景期待色の契約更新
- **背景**: `game-visual.spec.ts` の `BACKGROUND` は旧 `BG_COLOR '#0f0c18'`(15,12,24) を直書きしていた。P2 で背景パレットを刷新したため実態と乖離。
- **変更**: 中央サンプル領域(420-520,180-260)の実測色 (37,47,60) に更新（候補比較で 7999/8000 一致、閾値5000に対し余裕大）。他の背景依存アサーション（ground/gearBitHub/shoe）は不変。
- **理由**: 背景色変更は P2 の意図した仕様変更。テストは新パレットに追従させる（旧 DEC-006 と同種の契約更新）。

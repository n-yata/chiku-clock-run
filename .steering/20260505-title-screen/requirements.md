# 要求書: タイトル画面の追加

---

## 1. 背景

### 1.1 現状

- v0.4 時点のシーン構成: `BootScene`（テクスチャ生成）→ `GameScene`（ゲーム本体）の 2 シーン
- URL を開くと即 `GameScene` が始まるため、「ゲームが始まった感」がない
- ステージ 3 クリア後は `GameScene` が再ロードされ、ステージ 1 に戻る（クリアのフィードバックが弱い）
- 既存コミット: `595a76e`（v0.4）

### 1.2 やりたいこと

`BootScene` と `GameScene` の間に `TitleScene` を挿入し、ゲームタイトルと「スタート」のプロンプトを表示する。
ステージセレクト・ハイスコア表示は今回スコープ外とする。

---

## 2. ゴール

### 2.1 主目的

- URL を開いたユーザーが「ちゃんとしたゲームが始まる」という期待感を持てる入口画面を提供する
- Before: URL アクセス → 即ゲームプレイ（タイトルなし）
- After: URL アクセス → タイトル画面（キー or タッチでスタート） → ゲームプレイ

### 2.2 副次目的

- 全ステージクリア後にタイトルに戻るフローを作り、「終わり感」と「もう一度遊ぶ」への誘導ができるようにする
- 今後のタイトル拡張（ハイスコア、ステージセレクト）の土台シーンを整備する

---

## 3. スコープ

### 3.1 含むもの

- `TitleScene` の新規作成（`src/scenes/TitleScene.ts`）
- `main.ts` のシーン登録に `TitleScene` を追加（`BootScene` → `TitleScene` → `GameScene` の順）
- `GameScene` のステージ全クリア後の遷移先を `TitleScene` に変更（現行: `GameScene` 再起動）
- タイトル画面の表示要素:
  - ゲームタイトルテキスト
  - 「Press SPACE / Tap to Start」プロンプト（点滅アニメーション）
- キーボード（Space / Enter）・タッチ両対応のスタート操作

### 3.2 含まないもの

- ステージセレクト画面（後続スプリントに送る）
- ハイスコア / スコアランキング表示（後続スプリントに送る）
- タイトル専用 BGM の追加（既存 BGM アーキテクチャの変更を伴うため今回は対象外）
- キャラクターアニメーションや背景スクロール演出（後続スプリント）

---

## 4. 機能要件

### 4.1 シーン遷移フロー

1. ブラウザが URL を開く
2. `BootScene` でテクスチャ生成が完了する
3. `TitleScene` に自動遷移し、タイトル画面を表示する
4. ユーザーが Space / Enter キーを押す、または画面をタップする
5. `GameScene` に遷移し、ステージ 1 からゲームが始まる
6. 全ステージ（ステージ 3）クリア後、`TitleScene` に戻る

### 4.2 タイトル画面の表示仕様

| 要素 | 仕様 |
|------|------|
| ゲームタイトル | `gameConfig.ts` に定数 `GAME_TITLE` を追加し、テキスト表示（マジックナンバー禁止） |
| サブテキスト | 「Press SPACE / Tap to Start」（点滅: 1 秒周期） |
| レイアウト | 画面中央に縦並び配置。`Scale.RESIZE` に対応（リサイズ時に再配置） |
| 背景色 | 既存 `BG_COLOR` を使用 |

### 4.3 既存機能の互換要件

- `BootScene` → `GameScene` の直接呼び出し箇所（`main.ts`）を `TitleScene` 経由に変更しても、`GameScene` の内部ロジックは無変更
- 既存のモバイル向けレスポンシブ対応（`Scale.RESIZE` + orientationchange）は維持する
- HUD 座標補正ロジック（ズーム補正）には触らない

---

## 5. 非機能要件

### 5.1 パフォーマンス

- `TitleScene` は軽量（テキスト描画のみ）。追加のロード時間は体感ゼロを目標とする

### 5.2 信頼性

- タイトル画面でエラーが発生しても、R キーでリスタート（`TitleScene` 再開）できる動線を維持する

### 5.3 互換性・依存

- フロント: Phaser 3 の `Phaser.Scene` のみ使用。追加依存なし
- ハードコーディング禁止: ゲームタイトル文字列は `src/config/gameConfig.ts` の `GAME_TITLE` 定数に集約する

### 5.4 セキュリティ

- タイトルテキストはリテラル定数から参照。外部入力を描画テキストに渡さない（XSS 対策）

---

## 6. 制約・前提条件

- Phaser 3 の `scene.start()` / `scene.restart()` によるシーン管理で実装する
- `Scale.RESIZE` モード前提。固定解像度を仮定したレイアウト禁止
- HUD 座標補正（`MEMORY.md: Scale.RESIZE + カメラズーム時の HUD 座標補正`）の知見はタイトル画面にも適用すること（カメラズームなし想定だが setScrollFactor 等の副作用に注意）
- 実装後にクルトワ（security-engineer）レビュー必須

---

## 7. 受け入れ条件

- [ ] URL を開くと `BootScene` の後に `TitleScene` が表示される
- [ ] タイトルテキストと「Press SPACE / Tap to Start」プロンプトが画面中央に表示される
- [ ] プロンプトが点滅（約 1 秒周期）する
- [ ] Space / Enter キーで `GameScene`（ステージ 1）に遷移する
- [ ] 画面タップで `GameScene`（ステージ 1）に遷移する（モバイル対応）
- [ ] ステージ 3 クリア後に `TitleScene` に戻る
- [ ] ブラウザウィンドウリサイズ時にレイアウトが崩れない
- [ ] 既存ゲームプレイ（敵・コイン・ステージ進行・BGM/SE）が正常に動作する
- [ ] クルトワ（security-engineer）レビューで Critical/High なし
